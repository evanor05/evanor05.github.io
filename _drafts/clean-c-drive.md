电脑用久了之后，C 盘变红基本是迟早的事。

我以前看到 C 盘快满的时候，也会下意识想“是不是该删点什么”。但真正麻烦的地方在于：很多文件看起来都像垃圾，实际上却可能是系统或软件正在用的东西。所以清理 C 盘这件事，重点不是胆子大，而是先判断清楚。

## 适用场景

这篇文章适合 C 盘空间快满、但又不确定哪些文件能删的人。

目标不是“把能删的都删掉”，而是用风险尽量低的方法，先找出真正占空间的地方，再按优先级处理。

## 先说结论

清理 C 盘建议按这个顺序来：

1. 先看空间到底被谁占了。
2. 优先清理系统临时文件和回收站。
3. 再处理下载、桌面、微信/QQ 文件、浏览器缓存。
4. 最后再考虑迁移软件、游戏或开发环境。

不建议一上来就删 `Windows`、`Program Files`、`AppData` 里的陌生文件。

如果只记住一句话，就是：**先用系统工具清理，再处理自己的文件，最后才动软件和缓存目录。**

## 准备工作

- Windows 10 或 Windows 11
- 保持电脑能正常联网
- 重要文件先备份
- 不确定的文件先不要删

可以先打开“设置 -> 系统 -> 存储”，看 C 盘空间分类。

## 操作步骤

### 1. 使用系统自带存储清理

打开：

```text
设置 -> 系统 -> 存储 -> 临时文件
```

优先勾选这些项目：

- 临时文件
- 回收站
- 缩略图
- Windows 更新清理
- 传递优化文件

如果你不确定“下载”里有没有重要文件，不要勾选“下载”。

这一步通常风险最低，因为它清理的是系统已经识别出来的临时内容。

### 2. 清理桌面和下载目录

很多人的 C 盘变满不是因为系统，而是因为桌面和下载目录。

重点看：

```text
C:\Users\你的用户名\Desktop
C:\Users\你的用户名\Downloads
```

建议把大文件移动到 D 盘或移动硬盘，而不是直接删除。

尤其是桌面。很多人习惯把所有东西堆在桌面上，但桌面本身就在 C 盘用户目录里。

### 3. 检查微信、QQ 和浏览器缓存

常见占空间位置：

```text
文档\WeChat Files
文档\Tencent Files
```

如果聊天文件很多，可以在微信或 QQ 设置里调整文件保存位置，或者清理不需要的视频、图片和文件。

这类文件的特点是增长很隐蔽。你可能没有主动下载什么大文件，但聊天里接收的视频、压缩包和图片会一直累计。

### 4. 找出真正的大文件

如果前面几步效果不明显，可以使用磁盘分析工具查看空间分布。

可选工具：

- WizTree
- TreeSize Free
- WinDirStat

使用这类工具时，只把它当作“查找工具”，不要看到大文件就直接删。先确认它属于哪个软件、删除后会不会影响使用。

如果一个目录名字完全看不懂，先搜索一下目录名或软件名，再决定怎么处理。

### 5. 迁移大型软件或游戏

如果是游戏、虚拟机、开发环境占空间，清理临时文件意义不大。

更合理的做法是：

- 卸载后重新安装到 D 盘
- 在软件设置中修改缓存路径
- 把项目目录放到非系统盘

这一步比“清垃圾”更接近长期解决问题。因为有些东西本来就不该长期堆在 C 盘。

## 不建议直接删除的目录

下面这些目录不要手动乱删：

```text
C:\Windows
C:\Program Files
C:\Program Files (x86)
C:\Users\你的用户名\AppData
```

这些目录里确实可能有缓存，但也有大量系统和软件运行必需文件。没有明确判断前，不要手动删除。

## 常见问题

### 可以删除 `AppData` 吗？

不建议直接删除整个 `AppData`。如果某个软件缓存很大，应该进入软件设置里清理，或者确认具体目录用途后再处理。

### C 盘需要留多少空间？

日常使用建议至少留 20GB 以上。如果经常更新系统、装大型软件或做开发，建议留更多。

### 清理后很快又满了怎么办？

说明有软件持续把文件写到 C 盘。需要找到来源，比如聊天软件、浏览器下载、游戏缓存、虚拟机镜像或开发工具缓存。

## 总结

清理 C 盘最重要的是顺序：先判断，再清理；先处理低风险位置，再处理软件和大型文件。

真正长期有效的做法不是反复删除文件，而是把下载、聊天文件、项目目录和大型软件的位置规划好。

下次装软件或保存文件时，顺手多看一眼路径，可能比事后清理半小时更有效。
